# Xenium example datasets

Compact Xenium example datasets prepared for `scop` spatial workflows.

## Datasets

| Dataset | Object | Source | Intended use |
|---|---|---|---|
| `xenium_human_pancreas_sub` | Seurat object | `TENxXeniumData::sfe_human_pancreas()` | Small imaging-based spatial transcriptomics example for `scop` tutorials and tests. |

## Files

- `xenium_human_pancreas_sub.rds`: compact Seurat object generated by the script.
- `manifest.tsv`: checksums and basic metadata for released files.
- `scripts/create_xenium_human_pancreas_sub.R`: reproducible data preparation script.

## Build

Run from this repository root:

```r
source("Xenium/scripts/create_xenium_human_pancreas_sub.R")
create_xenium_human_pancreas_sub()
```

If the ExperimentHub download is slow, download the source RDS separately and
pass it to the script:

```r
create_xenium_human_pancreas_sub(
  source_rds = "path/to/sfe_human_pancreas.rds"
)
```

The source object is available through Bioconductor ExperimentHub as
`TENxXeniumData/sfe_human_pancreas.rds`.
