
# Dataset Backup Repository

This repository is used for storing and backing up various bioinformatics-related datasets. The data are mainly for backup purposes, and some are sourced from public databases or third-party projects.

## Resources

| Directory | Description |
|---|---|
| `AnimalTFDB4/` | Animal transcription factor and cofactor tables used by `scop::PrepareDB()`. |
| `CIBERSORT/` | CIBERSORT reference signature resources. |
| `CSPA/` | Cell surface protein annotation resources. |
| `CytoTRACE2/` | CytoTRACE2 model resources used by `scop`. |
| `motifs/` | Motif databases and annotation tables. |
| `scFEA/` | scFEA M168 model resources. |
| `scMetabolism/` | Metabolism gene set resources. |
| `tAge/` | Converted tAge model resources. |
| `Xenium/` | Compact Xenium example data preparation assets for `scop`. |
